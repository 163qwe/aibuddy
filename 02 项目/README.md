# 02 项目 · 进行中

> **一个项目一个子目录。** 正在做的事，都归到这儿。

## 目录约定

```
02 项目/
├── 项目A/
│   ├── README.md      ← 项目背景、目标、当前进度
│   ├── 素材/          ← 项目相关的原始资料
│   ├── 过程/          ← 中间草稿、讨论记录
│   └── 成果/          ← 最终交付物
└── 项目B/
```

## 项目 README 模板

每个项目建一个 README.md，说明：

```markdown
# 项目名称

**背景** — 为什么要做这件事
**目标** — 做完是什么样
**进度** — 当前到哪一步了
**下一步** — 接下来要做什么
**产出** — 最终交付物清单
```

## 规则

- 项目结束后，把它移到 `04 归档/`，并在归档目录留一份说明
- 项目的原始素材如果还没处理，先放 `01 收件箱/`
