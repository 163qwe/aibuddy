# 04 归档 · 存档区

> **已结束但要留档的东西。** 项目完了、结论定了，放这里。

## 归档什么

- 已完成的项目（从 `02 项目/` 移过来）
- 已定稿的成果文档
- 过期的方案、废弃的草稿
- 需要留证据的工作记录

## 归档规范

每个归档项留一份 README，说明：

```markdown
# 项目名称（归档）

**背景** — 当时为什么要做
**结论** — 最终结果是什么
**产出物** — 生成了哪些文件
**可复用经验** — 下次能借鉴什么
**归档日期** — 2026-XX-XX
```

## 规则

- 归档不是删除，内容仍然可查、可用
- 归档后，在 `00 驾驶舱/` 的「最近完成」里记一笔
- 有价值的经验，回头提炼一份进 `03 知识库/`
