# 01 收件箱 · 待处理区

> **所有新素材的第一站。** 扔进来就行，不用整理、不用分类、不用重命名。

## 放什么

- 网页文章、剪藏内容
- 突发想法、灵感
- 会议记录、对话截图
- 别人发来的文件
- 待处理的数据、素材

## 规则

1. 东西一律先扔这里，**不要直接放进正式目录**
2. 文件名随意，AI 会重新命名和归类
3. 格式不限，Markdown / 纯文本 / 图片都行
4. AI 处理完会告诉你每一项的去向，**你确认后**才进入 `02 项目/` 或 `03 知识库/`

## 常见命名建议（可选）

- `待整理-xxx`
- `文章-xxx`
- `想法-xxx`

> 不用纠结，写什么都行。这里越乱越好，整理是 AI 的活。
