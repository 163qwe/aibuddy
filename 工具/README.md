# 工具 · 脚本与模板

> **可复用的小工具放这里。** 一次写好，反复用。

## 放什么

- 脚本（Python / JS / Shell）
- 各类模板（报告、合同、周报、方案）
- 提示词模板（Prompt）
- 配置文件

## 工具 README 规范

每个工具一个子目录，内含说明：

```markdown
# 工具名称

**用途** — 解决什么问题
**用法** — 怎么调用
**依赖** — 需要什么环境/库
**示例** — 实际怎么用
```

## 命名规范

工具用 `领域_动作` 格式：

- `md_to_word` — Markdown 转 Word
- `batch_rename` — 批量重命名
- `report_template` — 报告模板

## 规则

- 一个工具一个目录，不要把无关脚本堆在一起
- 依赖装在自己的虚拟环境里，别污染全局
- 写清楚用法，否则过两周你自己也会忘
