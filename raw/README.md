# 原始素材存放区

这个文件夹存放所有未经处理的原始素材。

## 放什么进来？

- 网页文章（复制粘贴成 .md 或 .txt）
- 突发想法、灵感
- 读书高亮、摘抄
- 会议记录
- 推文/社交媒体上有价值的内容
- 截图、脑暴笔记

## 命名规范

| 类型 | 前缀 | 示例 |
|------|------|------|
| 网页文章 | `article-` | `article-ai-coding-tools.md` |
| 突发想法 | `idea-` | `idea-knowledge-graph.md` |
| 读书高亮 | `highlights-` | `highlights-deep-work.md` |
| 推文 | `tweet-` | `tweet-karpathy-second-brain.md` |
| 笔记 | `note-` | `note-meeting-20261031.md` |
| 脑暴 | `braindump-` | `braindump-product-ideas.md` |

## 规则

1. **不用整理**，直接扔进来
2. **不用重命名**，AI 会处理
3. **永不删除**，这是事实来源
4. 格式不限，Markdown、纯文本都行

> 原始素材越乱越好——整理是 AI 的活，不是你的活。
