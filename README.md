# AIBuddy — 个人工作台

一个盘搞定，不区分 C/D 盘。纯 Markdown 文件 + 一个可视化页面，没有数据库，没有专用软件。

## 目录结构

```
aibuddy/
├── AGENTS.md          ← 规则文件：AI 的操作手册（开工前必读）
├── README.md          ← 本文件
├── 00 驾驶舱/         ← 总览入口 + 可视化工作台
│   ├── README.md         今日概览、项目进度、待决策事项
│   └── app/              可视化工作台（任务/习惯/记账/日志）
├── 01 收件箱/         ← 待处理：新素材都扔这里
├── 02 项目/           ← 进行中：一个项目一个子目录
├── 03 知识库/         ← 长期资产：一个概念一页，互相链接
├── 04 归档/           ← 已结束项目的存档
├── huancun/           ← 临时文件、中间产物，可随时清
├── 工具/              ← 脚本、模板、可复用小工具
├── raw/ wiki/ outputs/ ← Karpathy 三层知识库（兼容层）
└── docs/ src/         ← 项目文档与源码
```

## 核心工作流

```
新素材 ──→ 01 收件箱 ──(你确认)──→ 02 项目 / 03 知识库
                                        │
AI 生成 ──────────────────────────────→ 04 归档
```

1. **投喂** — 东西直接扔进 `01 收件箱/`，不用整理
2. **分拣** — 让 AI 按 `AGENTS.md` 规则分类，告诉你每一项的去向
3. **验收** — 你确认后才进正式目录
4. **复用** — 有价值的提炼进 `03 知识库/`，用 `[[主题]]` 互链
5. **归档** — 项目结束移进 `04 归档/`，留一份复盘说明

## 可视化工作台

`00 驾驶舱/app/index.html` — 直接双击浏览器打开即可。

包含：总仪表盘、任务管理、习惯打卡、记账管理、日志复盘。
数据存浏览器 localStorage，关掉不丢。

## 常用指令

```
读取 01 收件箱/ 的所有内容，按 AGENTS.md 规则分类整理，
告诉我每一项的处理理由。

根据当前各目录的实际状态，更新 00 驾驶舱/README.md。

把成果先写到 01 收件箱/，并说明用了哪些来源、需要我验收什么。
```

## 约定

- 主分支 `main`，提交信息用祈使句
- 不提交密钥、令牌、`.env`
- 所有文件都在这一个工作空间下，不跨盘

## 设计哲学

> 简单胜过复杂。规则只写一次，AI 负责执行。
> 你负责投喂和验收，AI 负责整理和维护。
> 每一次提问都让工作台更聪明——这就是复利循环。
