# aibuddy

一个用于实验与迭代的 AI 助手项目仓库。

> 本仓库由 WorkBuddy 于 2026-10-30 初始化，用于验证 GitHub 读写链路并作为后续开发的起点。

## 目录结构

```
aibuddy/
├── README.md           项目说明（本文件）
├── .gitignore          版本控制忽略规则
├── .editorconfig       跨编辑器统一编码与缩进
├── docs/
│   └── roadmap.md      路线图与待办
└── src/
    └── README.md       源码目录说明
```

## 快速开始

当前仓库为初始化状态，尚无运行时代码。确定技术栈后，按以下顺序补齐：

1. 在 `src/` 下创建源码目录与入口文件；
2. 增加依赖清单（如 `package.json` / `pyproject.toml`）；
3. 在 `docs/roadmap.md` 中登记下一步计划。

## 约定

- 主分支：`main`
- 提交信息使用祈使句，一句话说明「做了什么」
- 不提交密钥、令牌、`.env` 等敏感信息
