# AIBuddy — 个人知识库（第二大脑）

基于 [Karpathy LLM Wiki 方法](https://x.com/nickspisak_/status/2040448463540830705) 搭建的个人知识库系统。

## 核心架构

三个文件夹 + 一个规则文件，没有数据库，没有专用软件，纯 Markdown 文件。

```
aibuddy/
├── raw/        # 原始素材层 — 文章、笔记、想法，什么都往里扔
├── wiki/       # 知识层 — AI 编译的主题页，互相链接
├── outputs/    # 产出层 — AI 生成的回答、报告、研究
├── docs/       # 项目文档与路线图
├── src/        # 源码目录
└── CLAUDE.md   # 规则文件 — AI 的操作手册
```

## 工作流

1. **捕捉 (Capture)** — 把看到的、想到的内容存进 `raw/`，不用整理
2. **编译 (Compile)** — 让 AI 读取 `raw/`，提取概念，生成 `wiki/` 主题页
3. **查询 (Query)** — 向 AI 提问，基于知识库内容作答，存入 `outputs/`
4. **体检 (Lint)** — 定期检查知识库健康，防止错误复利增长

## 快速开始

1. 把任何素材扔进 `raw/` 文件夹
2. 让 AI 编译：读取 `raw/` 所有内容，按 `CLAUDE.md` 规则在 `wiki/` 生成主题页
3. 向 AI 提问，答案基于你自己的知识库

## 设计哲学

> 简单胜过复杂。三个文件夹 + 一个规则文件，胜过任何花哨的应用。
> 你负责输入和提问，AI 负责整理和维护。
> 每一次提问都让知识库更聪明——这就是复利循环。

## 约定

- 主分支：`main`
- 提交信息使用祈使句，一句话说明「做了什么」
- 不提交密钥、令牌、`.env` 等敏感信息
