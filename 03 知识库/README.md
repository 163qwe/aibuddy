# 03 知识库 · 长期资产

> **值得反复复用的东西放这里。** 这层是整个工作台最有价值的部分。

## 什么算知识库

- 经过提炼的方法论、经验、结论
- 可复用的模板、清单、流程
- 值得长期查阅的技术笔记
- 你的个人判断和观点

## 与 Karpathy 三层法对照

这个目录对应 Karpathy 方案的中间层：

```
raw/        ← 原始素材（对应 01 收件箱）
wiki/       ← 知识库  （对应 03 知识库）
outputs/    ← 产出成果（对应 04 归档 或 02 项目/成果）
```

## 组织方式

**一个概念一页，不是一篇文章一页。**

用 `[[主题名]]` 格式互相链接，根目录维护 `INDEX.md` 索引。

```markdown
# 主题名称

（2-3 句摘要）

## Key Concepts

## Details

## Connections
- [[相关主题A]]
- [[相关主题B]]

## Sources
- 来源：xxx.md
```

## 规则

1. **绝不删除**这里的文件——这是长期资产
2. 每页必须有 `Connections` 章节，至少链接 1 个相关页面
3. 两个来源冲突时**保留分歧**，不要悄悄选边
4. AI 负责维护，你只负责读和提问
