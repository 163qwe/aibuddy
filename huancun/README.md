# huancun · 临时缓存区

> **临时文件、中间产物、下载的原始文件都在这里。** 随时可以清空。

## 放什么

- AI 生成的中间稿（还没验收的）
- 抓取下来的网页原始内容
- 调试用的临时脚本
- 转换过程的中间文件
- 任何「先放这儿，之后再说」的东西

## 规则

1. 临时文件**一律**进这里，不要污染正式目录
2. 这里的文件随时可删，不承担存档职责
3. 有价值的东西记得挪到 `02 项目/` 或 `03 知识库/`
4. 定期清理（建议每周一次）

## 命名建议

- `tmp-xxx`
- `draft-xxx`
- `raw-xxx`

> 这个目录名就是拼音「缓存」，跟 WorkBuddy 的缓存机制无关，纯粹是博主的命名习惯。
